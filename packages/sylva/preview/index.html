Sylva — a forest & sage palette

A small, reusable set of color tokens: a forest-green brand ramp, a muted sage for surfaces and edges, hue-free neutrals for content, and four feedback hues. Two tiers — raw primitives and semantic aliases — delivered as W3C design tokens.

Lifted from an existing site palette, mascot and all. The three primary greens (#0d4d14, #1b5e20, #2e7d32), the accent #66bb6a, and the sage surface/border/muted values are preserved as anchor steps; the rest of each ramp is generated around them.

Adopting it

Using the tokens

The source of truth is two DTCG files. Primitives hold hex values; semantic tokens hold references like {color.green.800} and are split into light and dark groups that mirror each other.

tokens/primitives.tokens.jsonGreen, sage, neutral, feedback ramps + base colors
tokens/semantic.tokens.jsonbg · text · border · action · feedback, per theme
brand/gnome.svgThe mascot — standalone pixel SVG
preview/index.htmlThis page

Generate CSS custom properties with Style Dictionary v4 (opt-in — not committed here):

npm i -D style-dictionary

// sd.config.mjs
export default {
  source: ['tokens/**/*.tokens.json'],
  platforms: {
    css: {
      transformGroup: 'css',
      buildPath: 'dist/',
      files: [{ destination: 'sylva.css', format: 'css/variables' }]
    }
  }
};

Then in a project: @import '@scheigs/sylva/dist/sylva.css'; and map the semantic vars into your Tailwind @theme block.

The mascot

Gnome mark

The gnome travels with the palette as brand/gnome.svg — a 14×23 pixel grid of flat <rect>s, no gradients, scales crisp to any size. Its 14 colors are its own (hat reds, beard blue-greys, a moss-green collar); they sit outside the token system but are kept here so the whole identity lives in one place.
